GeoLibre Assets

Static file hosting for GeoLibre. Files committed to the repository are served from this domain.

Usage

https://assets.geolibre.app/<path-in-repo>

# e.g. images/logo.png in the repo:
https://assets.geolibre.app/images/logo.png

Directories

Path Contents
data/ Sample datasets (GeoJSON, PMTiles, CSV, Parquet)
images/ Images, logos, icons, screenshots
styles/ MapLibre style JSON and sprite resources
fonts/ Font glyph PBFs
